痛点 1 · Waitlist 与注册之间断层

等候名单收集的是邮箱，但注册要走号码验证；缺乏自动化衔接，大量 Waitlist 用户拿到邀请后并未完成注册就流失。

解法 · OTP 一键认证 + 邮件发码旅程

Email 分层预热养熟 → 发码即触达 → Silent Auth / OTP 一键完成号码验证，把"邮箱"顺滑接到"注册用户"。

痛点 2 · 首次创作 Aha 未闭环

用户注册后若没在早期完成"上传角色→生成首张故事卡"，几乎不会留下来；靠自然探索发现率低。

解法 · 行为触发的 Aha 催化旅程

注册后观察窗口内未上传即触达引导；首卡生成瞬间用拟人文案推动分享与二次创作，放大 Aha。

痛点 3 · 群发式推送打扰、伤推送权限

一刀切群发既低效又消耗推送授权；对多语言、多时区的北美用户尤其需要精细化而非大水漫灌。

解法 · 行为分层 + 频控 + 时区触达

按行为/沉默深度分层、终端时区发送、每日/每周频控去重；先观察自然转化，未完成才触达。

痛点 4 · 早期没数据资产沉淀

Waitlist 邮箱、注册号码、设备标识分散，无法拼成一个用户，也就无法做个性化与召回。

解法 · CDP 统一身份（EUID）

邮箱 / 手机号 / 设备 RID 按优先级自动合并为一个 EUID，跨渠道行为归一，为个性化与全生命周期运营打底。

五、核心旅程详细编排

旅程 1：Waitlist 分层预热 → 发码激活

业务痛点

等候名单只有邮箱，发码后不少人没回来注册。缺乏养熟与发码即时衔接。

旅程组件配置

进入条件：事件：加入等候名单

提前退出：事件：完成注册

转化统计：事件：注册成功，监听 3 天

再次进入：不可（Waitlist 为一次性）

可发送时间：发码触达前置 9:00-20:00 终端时区

预期效益

Waitlist 激活率 +10~20%（估算）；Email 主推、SMS 仅对未注册兜底以控成本。

旅程 2：OTP 一键认证 + 首角上传引导

业务痛点

验证码流程繁琐拉高注册流失；注册后不上传首个角色的用户基本留不住。

旅程组件配置

进入条件：事件：启动注册

提前退出：事件：完成首个角色上传

转化统计：事件：首角上传成功，监听 1 天

渠道递进：App Push（即时）→ Email（24h 后补触达）

可发送时间：刚注册处活跃窗口不加限制；24h 后触达前加时段

预期效益

Silent Auth 降注册摩擦，注册完成 +15~25%；首角上传率 +15~25%（估算）。

旅程 3：首卡 Aha 催化 + 故事卡分享裂变

业务痛点

首张故事卡是 Aha 时刻，但用户常"生成即离开"，UGC 分享带来的裂变没被激活。

旅程组件配置

进入条件：事件：生成首张故事卡

提前退出：事件：完成分享 / 再创作

文案：角色第一人称拟人（"你的角色 {name} 有话想说"）

转化统计：事件：分享成功，监听 1 天

可发送时间：即时 Push 不限；邮件走 10:00-21:00 终端时区

预期效益

分享率 +20~35%（估算）；分享带来 K 因子提升，反哺获客成本。

旅程 4：每日 Life Loop 世界唤醒

业务痛点

世界 / 好友产生新事件却触达不到用户就流失；日常回访缺乏自动化的即时提醒。

旅程组件配置

进入条件：事件：世界产生新事件（NPC / 好友互访）

提前退出：事件：回访（打开 App）

频控：普通用户每日 ≤2 条 Push

转化统计：事件：回访，监听 当日

可发送时间：本地黄金时段，终端时区

预期效益

DAU/MAU +8~15%（估算）；iOS + Android 双端 App Push 统一实时触达。

旅程 5：AI 生成额度耗尽 → 订阅转化

业务痛点

生成额度是核心付费点，但额度耗尽的关键时刻没有及时的转化引导。

旅程组件配置

进入条件：事件：生成额度归零（应用内）

提前退出：事件：完成订阅

分支：属性：用户价值分层（高价值推年费 / 低价值推免费试用）

转化统计：事件：订阅成功，监听 3 天

可发送时间：应用内即时；邮件与 Push 走终端时区

预期效益

订阅转化 +3~7%（估算）；额度耗尽瞬间的即时应用内消息转化效率最高。

旅程 6：沉睡用户分层召回

业务痛点

沉默用户一刀切群发既低效又伤权限；不同沉默深度该用不同力度与通道。

旅程组件配置

进入条件：属性：最后打开距今 >3 天

分支：属性：沉默深度 3-6 天 / 7-29 天 / ≥30 天

提前退出：事件：回归（打开 App）

再次进入：可，间隔 15 天

可发送时间：各触达前置 终端时区时段

预期效益

回归率 +20~40%（估算）；渠道成本递进 App Push → Email → SMS，深度流失才上短信。

六、北美渠道选型参考

北美市场渠道适配相对值（示意，非精确数据）：WhatsApp 在北美渗透低，Email/SMS 是主力，App Push 双端覆盖后为实时行为触达的首选。

主力通道

补充与暂缓

Web Push 可覆盖官网访客、扩大触点；WhatsApp 北美非首选，暂不铺设，后续视区域增长再评估。

七、合规与安全

北美 / 全球法规
  • 邮件 CAN-SPAM 合规（发件人标识、一键退订）
  • CCPA / GDPR：数据删除 / 导出 / 同意管理
  • UGC 平台未成年保护（COPPA / GDPR-K）：独立频控、不投付费文案
数据与传输安全
  • 全链路 TLS 加密、PII 脱敏、手机号哈希传输
  • RBAC 权限、审计日志、记录留存（如 60 天）
  • 已通过 GDPR、SOC 2 认证
触达与内容护栏
  • 频控去重、勿扰时段、终端时区发送
  • 触达链接仅指向已审核的故事卡 / 内容，对接内容安全
  • 照片仅用于生成，MA 侧接收匿名事件 ID
