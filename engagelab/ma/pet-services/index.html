EngageLab MA · 宠物服务平台增长方案

宠物是"强周期 + 高情感"的品类——疫苗、驱虫、洗护、口粮都有明确的周期节律， 而宠物档案（品种、年龄、体重）一旦建立，几乎所有服务都能被精准预测与提醒。 本方案以 宠物建档激活、疫苗驱虫周期提醒、洗护预约与履约、口粮耗材复购、就医与健康随访、会员订阅与沉默召回 六大旅程切入， 统一编排 App Push（主力）+ SMS + Email + WhatsApp 四类通道。

极光 / App Push（周期提醒） SMS（预约与就医节点） Email（健康档案/账单） WhatsApp（门店沟通）

注：下文所有转化率、提升幅度为宠物行业估算区间，落地以实测为准。健康类提醒不构成兽医诊疗建议。

痛点 1 · 用户不建宠物档案

没有宠物品种、年龄、体重等档案，平台就无法预测疫苗、驱虫、口粮任何周期，运营完全失去抓手。

解法 · 宠物建档激活旅程

用"建档后自动提醒疫苗驱虫时间、领取新宠礼包"驱动建档，把档案变成运营的基础设施。

痛点 2 · 疫苗驱虫周期错过

宠物主容易忘记疫苗与驱虫时间，既影响宠物健康，平台也损失掉最确定的服务收入。

解法 · 周期性健康提醒

按品种与年龄自动推算疫苗、驱虫周期，提前提醒并直连预约，是转化最确定的旅程。

痛点 3 · 洗护爽约与复购断层

预约洗护不到店浪费门店资源；口粮猫砂等耗材用完不复购，直接流向电商平台。

解法 · 履约提醒 + 耗材补货

洗护多段提醒降低爽约；按宠物体重与规格推算口粮消耗周期，提前推补货。

痛点 4 · 就医后无随访、老龄需求未覆盖

看病后不复诊、不服药，健康结果差；宠物进入老年期后的体检与专用食品需求未被识别。

解法 · 就医随访 + 年龄阶段运营

就医后随访用药与复诊；按宠物年龄自动切换幼年/成年/老年阶段的服务与商品推荐。

五、核心旅程详细编排

旅程 1：宠物建档激活

业务痛点

没有宠物档案就无法预测任何服务周期，整个自动化运营失去基础。

旅程组件配置

进入条件：事件：注册成功且未建宠物档案

提前退出：事件：完成宠物建档

价值感："建档后自动提醒疫苗驱虫时间 + 新宠礼包"

分支：属性：是否已填品种（补全年龄体重以精准推算周期）

预期效益

建档率 +30~50%（估算）；档案是宠物行业所有自动化运营的基础设施。

旅程 2：疫苗 / 驱虫周期提醒

业务痛点

宠物主容易忘记疫苗与驱虫时间，既影响宠物健康，平台也损失确定性收入。

旅程组件配置

进入条件：属性：按品种年龄推算的疫苗/驱虫周期临近

分支：属性：服务类型（疫苗 / 体内驱虫 / 体外驱虫）

递进：提前 7 天 → 提前 1 天 → 逾期提醒

提前退出：事件：完成预约或到店服务

预期效益

服务转化 +30~50%（估算）；这是宠物行业转化最确定、ROI 最高的旅程。

旅程 3：洗护预约与履约提醒

业务痛点

预约洗护不到店浪费门店资源与档期，门店满意度与平台履约口碑双受损。

旅程组件配置

进入条件：事件：洗护预约成功 / 属性：上次洗护距今超周期

时间轴：预约确认 → T-24h → T-2h（含门店地址）→ 服务后评价

分类：预约类为服务通知，不受营销退订限制

周期唤醒：按毛发类型推算的洗护周期主动提醒

预期效益

到店率 +20~35%（估算）；周期性洗护是稳定的高频服务收入来源。

旅程 4：口粮 / 耗材智能补货

业务痛点

口粮、猫砂等耗材用完不在平台复购，直接流向综合电商，商城价值无法沉淀。

旅程组件配置

进入条件：属性：按宠物体重与购买规格推算的消耗周期临近

分支：属性：品类（主粮 / 猫砂 / 零食保健）

提前量：预计用完前 5-7 天提醒，留出配送时间

提前退出：事件：完成复购

预期效益

复购频次 +25~45%（估算）；按实际消耗推算比统一促销精准得多。

旅程 5：就医随访 + 健康管理

业务痛点

看病后不按时喂药、不复诊，治疗效果差，宠物主对平台医疗服务信任受损。

旅程组件配置

进入条件：事件：完成就诊

阶段：用药周期提醒 → 恢复情况随访 → 复诊提醒

合规：仅做周期提示与就诊引导，不构成兽医诊疗建议

提前退出：事件：完成复诊 / 疗程结束

预期效益

复诊率 +20~35%（估算）；医疗闭环是宠物平台最高客单的服务线。

旅程 6：会员订阅 + 年龄阶段运营

业务痛点

高频用户未转会员则 LTV 受限；宠物进入老年期后的体检与专用食品需求未被识别。

旅程组件配置

进入条件：属性：高频消费用户 / 宠物年龄阶段变化 / 长期未活跃

分支：属性：触发类型（会员转化 / 年龄阶段推荐 / 沉默召回）

年龄运营：幼年疫苗与训练 → 成年绝育与保健 → 老年体检与处方粮

提前退出：事件：开通会员 / 完成消费

预期效益

会员转化与召回 +20~35%（估算）；按宠物年龄自然演进的推荐接受度极高。

六、渠道选型参考

宠物服务渠道适配相对值（示意）：App Push 是周期提醒的绝对主力（成本近零、时效可控），SMS 用于预约与就医关键节点，Email 承载健康档案与账单，WhatsApp 在门店与宠物主沟通中价值高。

主力通道

App Push（疫苗驱虫、洗护、补货等全部周期提醒，宠物主对这类提醒接受度极高）。

情感化文案

宠物品类适合用宠物口吻的情感化文案（"该给我打疫苗啦"），打开率显著高于功能性表述。

七、合规与安全

宠物医疗边界
  • 健康提醒不构成兽医诊疗建议
  • 用药提醒仅做周期提示，不做剂量与用药指导
  • 遵循当地宠物医疗与药品监管要求
数据法规
  • GDPR / CCPA：数据删除 / 导出 / 同意管理
  • PII 脱敏、RBAC 权限、全链路 TLS
  • 已通过 GDPR、SOC 2 认证
触达护栏
  • 周期提醒频控与去重，避免多宠物用户被重复打扰
  • 服务预约类通知独立于营销退订
  • 勿扰时段、记录留存（如 60 天）
