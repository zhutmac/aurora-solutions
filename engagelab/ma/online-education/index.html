EngageLab MA · 在线教育 / 语言学习出海增长方案

在线教育的增长本质是"学习习惯的养成"——用户装了 App 却不上第一课、上了课却断更、试用期结束就流失。 本方案把"买量拉来的一次性下载"升级为"从首课到续订的自动化学习生命周期运营"， 以 首课激活、学习连续性(Streak)守护、试用转订阅、断更分层召回、续订与升级、社群与结课激励 六大旅程切入， 统一编排 App Push + Email + Web Push + SMS/WhatsApp 四类通道。

一、为什么在线教育必须做学习生命周期自动化

首课门槛
下载后不上第一课的用户，几乎不可能付费
习惯驱动

注：下文所有转化率、提升幅度为在线教育行业估算区间，落地以实测为准。

痛点 1 · 下载了不上第一课

买量把用户拉进来，却卡在"注册完不知道学什么"，首课完成率低，后续所有转化无从谈起。

解法 · 首课激活旅程

注册后先观察，未开课即触达；用"5 分钟入门测试 + 个性化学习路径"降低启动门槛。

痛点 2 · 学习断更、习惯没养成

学习是反人性的，缺乏及时提醒与正反馈，用户学两天就断，Streak 一断基本不回来。

解法 · Streak 守护 + 每日提醒

按用户历史活跃时段智能提醒；Streak 将断时即时挽救（补签卡/鼓励文案），把学习变成习惯。

痛点 3 · 试用到期不付费

免费试用结束是最大付费节点，但缺乏分层引导——深度用户与浅度用户该用完全不同的话术。

解法 · 试用转订阅分层旅程

按试用期学习深度分层：深度用户用"学习成果数据"背书直推年费，浅度用户先激活价值感。

痛点 4 · 续订流失、缺乏成就感

订阅到期无提醒即静默流失；学完课程没有结课仪式与下一步引导，复购与口碑都丢了。

解法 · 续订前置 + 结课激励

T-7/T-3/T-1 递进续订提醒并展示学习成果；结课发证书、推荐进阶课与好友邀请，形成闭环。

五、核心旅程详细编排

旅程 1：首课激活（Aha 时刻）

业务痛点

注册后不上第一课的用户几乎不会付费，"不知道学什么"是最大启动门槛。

旅程组件配置

进入条件：事件：注册成功

提前退出：事件：完成首课

机制：先观察 1h 自然开课，未开课才触达

转化统计：事件：首课完成，监听 3 天

预期效益

首课完成 +15~30%（估算）；入门测试 + 个性化路径显著降低启动门槛。

旅程 2：学习连续性 Streak 守护

业务痛点

学习反人性，Streak 一断基本不回来；固定时间群发提醒打开率低且打扰。

旅程组件配置

进入条件：属性：当日尚未学习

分支：属性：当前 Streak 天数（有 Streak 保护 / 无 Streak 常规提醒）

智能时机：按用户历史活跃时段推送，终端时区

频控：每日 ≤2 条，完成学习即退出

预期效益

次日留存 +10~20%（估算）；"Streak 将断"是教育产品最强的行为钩子。

旅程 3：试用到期转订阅

业务痛点

试用到期是最大付费节点，一刀切促销既浪费深度用户，也吓跑浅度用户。

旅程组件配置

进入条件：属性：试用到期前 3 天

分支：属性：试用期学习深度（≥5 天 / <5 天）

提前退出：事件：完成订阅

递进：T-3 → T-1 → T+3 三段，各自独立文案

预期效益

试用转付费 +25~40%（估算）；"你已学 X 天、掌握 Y 词"的成果背书比单纯打折更有效。

旅程 4：断更学员分层召回

业务痛点

连续 3 天不学习后回归意愿断崖下滑，且不同断更深度需要不同力度。

旅程组件配置

进入条件：属性：连续未学习 >3 天

分支：属性：断更深度 3-6 / 7-14 / ≥15 天

提前退出：事件：回归学习

再次进入：可，间隔 15 天

预期效益

回归率 +20~40%（估算）；渠道成本递进 Push→Email→WhatsApp/SMS。

旅程 5：订阅续订 + 课程升级

业务痛点

订阅到期无提醒即静默流失；月费用户缺乏转年费的引导，LTV 受限。

旅程组件配置

进入条件：属性：订阅到期前 7 天

分支：属性：订阅类型（月费转年费 / 年费续订优惠）

递进：T-7 学习成果 → T-3 续订权益 → T-1 双通道 → T+7 召回

提前退出：事件：续订成功

预期效益

续订率 +15~25%（估算）；展示"本期学习成果"是最有效的续订说服力。

旅程 6：结课激励 + 邀请裂变

业务痛点

学完课程没有仪式感与下一步引导，成就感与口碑传播都被浪费。

旅程组件配置

进入条件：事件：完成课程 / 达成学习里程碑

提前退出：事件：完成分享 / 报名进阶课

内容：结课证书 + 学习成就卡 + 进阶课推荐 + 邀请好友奖励

转化统计：事件：分享/报名，监听 7 天

预期效益

邀请注册 +15~25%（估算）；成就卡分享是教育产品天然的低成本获客来源。

App Push（每日学习提醒、Streak 守护、智能时机）+ Email（学习周报、结课证书、续订与账单）。

补充通道

Web Push 覆盖网页端学员；SMS/WhatsApp 用于深度断更召回、K12 场景的家长端触达。

七、合规与安全

未成年人保护
  • COPPA / GDPR-K：未成年账号独立频控路径
  • 不向未成年人投放付费促销文案
  • K12 场景付费类触达定向家长端
数据法规
  • GDPR / CCPA：数据删除 / 导出 / 同意管理
  • PII 脱敏、RBAC 权限、全链路 TLS
  • 已通过 GDPR、SOC 2 认证
触达护栏
  • 学习提醒频控（每日 ≤2 条）、勿扰时段
  • 邮件 CAN-SPAM 一键退订、偏好中心
  • 终端时区发送、记录留存（如 60 天）
