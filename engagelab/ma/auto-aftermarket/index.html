EngageLab MA · 汽车后市场（保养 / 维修）增长方案

汽车后市场是"强周期 + 高确定性"的生意——保养按里程与时间、保险与年检按年度、轮胎电瓶按寿命， 只要有车辆档案，几乎所有需求都能被精准预测。而车主流失往往只是因为"到期时别家先提醒了"。 本方案以 车辆建档激活、保养周期提醒、到店履约与施工透明、年检保险等年度提醒、易损件更换与增购、会员与沉默召回 六大旅程切入， 统一编排 App Push + SMS + WhatsApp + Email 四类通道。

极光 / App Push（周期提醒） SMS（到期与施工节点） WhatsApp（门店沟通） Email（工单/发票）

一、为什么汽车后市场必须做车辆周期运营

档案是钥匙
无车型、里程、购车日期就无法预测任何需求
高确定性
保养/年检/保险周期明确，需求可精准预测
先提醒者赢
车主往往在谁先提醒时就选择了谁
信任敏感
维修不透明是行业最大的信任痛点

注：下文所有转化率、提升幅度为汽车后市场行业估算区间，落地以实测为准。

痛点 1 · 车主不建车辆档案

没有车型、里程、购车日期，平台无法预测保养与年检周期，运营完全失去抓手。

解法 · 车辆建档激活

用"自动提醒保养与年检时间、专属保养方案"驱动建档，把档案做成运营基础设施。

痛点 2 · 保养到期被别家先抢走

保养需求高度确定，但谁先提醒车主往往就选谁，不提醒等于把客户送给竞争对手。

解法 · 保养周期精准提醒

按里程与时间双维度推算保养节点，提前提醒并直连预约与报价，抢占决策先机。

痛点 3 · 维修不透明引发不信任

车放在店里不知道在修什么、要多久、加了什么项目，是行业最大的信任痛点。

解法 · 施工进度透明化

接车、检测、报价确认、施工中、完工全节点推送，增项必须车主确认，建立信任。

痛点 4 · 年度需求与易损件流失

年检、保险续保、轮胎电瓶更换等高价值需求未被识别，白白流向 4S 店或竞品。

解法 · 年度提醒 + 易损件预测

按购车日期推算年检保险时点；按里程与使用年限预测轮胎、电瓶、刹车片更换需求。

五、核心旅程详细编排

旅程 1：车辆建档激活

业务痛点

没有车辆档案就无法预测保养与年检周期，全部自动化运营失去基础。

旅程组件配置

进入条件：事件：注册成功且未建车辆档案

提前退出：事件：完成车辆建档

价值感："自动提醒保养与年检时间、生成专属保养方案"

分支：属性：是否已填车型（补里程与购车日期以精准推算）

预期效益

建档率 +30~50%（估算）；车辆档案是后市场所有周期运营的前提。

旅程 2：保养周期精准提醒

业务痛点

保养需求高度确定，但谁先提醒车主往往就选谁，不提醒等于送客给竞品。

旅程组件配置

进入条件：属性：按里程或时间推算的保养节点临近

分支：属性：保养类型（小保养 / 大保养）

递进：提前 15 天 → 提前 3 天 → 逾期提醒（附套餐报价）

提前退出：事件：完成预约或到店

预期效益

保养转化 +30~50%（估算）；这是后市场确定性最高、ROI 最好的旅程。

旅程 3：到店履约 + 施工进度透明

业务痛点

车放在店里不知道在修什么、要多久、加了什么项目，是行业最大的信任痛点。

旅程组件配置

进入条件：事件：预约成功 / 车辆进厂

时间轴：预约提醒 → 接车确认 → 检测报告 → 增项确认 → 完工提醒 → 评价

关键：任何增项必须车主确认后施工（信任基石）

分类：服务类通知，不受营销退订限制

预期效益

到店率 +20~35%、投诉下降；透明化是后市场最有效的口碑建设。

旅程 4：年检 / 保险年度提醒

业务痛点

年检与保险续保是高客单需求，不提醒就流向 4S 店或保险公司直销。

旅程组件配置

进入条件：属性：按购车/上牌日期推算的年检或保险到期临近

分支：属性：业务类型（年检代办 / 保险续保）

递进：提前 30 天 → 15 天 → 7 天 → 逾期提醒（年检逾期有罚则）

提前退出：事件：完成预约或投保

预期效益

年度业务转化 +25~40%（估算）；年检与保险是后市场最高客单的两项业务。

旅程 5：易损件更换预测与增购

业务痛点

轮胎、电瓶、刹车片等易损件到寿命未被提醒，车主临时就近处理，需求流失。

旅程组件配置

进入条件：属性：按里程与使用年限推算的易损件寿命临近

分支：属性：部件类型（轮胎 / 电瓶 / 刹车片 / 雨刷）

内容：安全提示 + 检测优惠 + 与保养合并施工的便利性

提前退出：事件：完成更换

预期效益

客单价 +15~25%（估算）；与保养合并施工能显著提升转化与车主便利。

旅程 6：会员卡 + 沉默车主召回

业务痛点

高频车主未办会员卡则 LTV 受限；180 天未到店的车主基本已被竞品接走。

旅程组件配置

进入条件：属性：高频到店车主 / 180 天未到店

分支：属性：触发类型（会员转化 / 沉默召回）

提前退出：事件：办卡 / 到店消费

再次进入：可，间隔 60 天（低频行业避免过度打扰）

预期效益

会员与召回 +20~35%（估算）；会员卡（预存/套餐）是锁定车主的最有效手段。

六、渠道选型参考

汽车后市场渠道适配相对值（示意）：App Push 承载周期提醒主力，SMS 是年检保险等到期节点的必达兜底（车主可能未装 App），WhatsApp 在新兴市场门店沟通中价值高，Email 承载工单与发票。

主力通道

App Push（保养、易损件、年检等全部周期提醒）+ SMS（未装 App 车主与法定期限类必达提醒）。

多周期去重

保养、年检、保险、易损件多条周期可能同期触发，必须做旅程间去重与合并，避免同一车主被连续轰炸。

七、合规与安全

车辆与个人数据
  • 车牌、VIN 等信息严格脱敏，最小化使用
  • 行驶数据与位置信息受限采集
  • GDPR/CCPA 数据删除与同意管理
服务透明合规
  • 增项必须车主确认后施工，留存确认记录
  • 报价与优惠如实展示，不做虚假促销
  • 安全类提示不夸大恐吓
触达护栏
  • 多周期旅程间去重与合并，避免轰炸
  • 施工与到期类服务通知独立于营销退订
  • 勿扰时段、记录留存（如 60 天）
