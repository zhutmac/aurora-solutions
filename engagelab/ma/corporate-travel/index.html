EngageLab MA · 企业差旅管理（TMC）增长方案

企业差旅是典型的 B2B2E 场景——企业采购、员工使用、财务管控三方诉求不同： 企业要合规与省钱、员工要方便、财务要报销清晰。员工绕开平台自己订（线下预订）是最大的价值流失。 本方案以 企业开通与员工激活、差旅预订引导与合规提示、行程履约与异常处理、报销与发票闭环、差旅政策与用量分析、企业续约与账户健康 六大旅程切入， 统一编排 Email（主力）+ App Push + SMS + 应用内 四类通道。

Email（B 端标准通道） App Push（员工行程） SMS（航变等紧急） 应用内（预订引导）

痛点 1 · 企业签约后员工不用

企业开通了账户但员工不知道、不会用，平台渗透率低，企业续约时看不到价值。

解法 · 员工激活旅程

批量激活员工账号并引导首次预订，用"免垫资、自动报销"等员工侧价值驱动使用。

痛点 2 · 员工绕开平台线下自订

员工嫌平台麻烦或觉得外面更便宜就自己订，企业失去管控、TMC 失去交易额。

解法 · 预订引导 + 合规提示

差旅申请通过后即引导在平台预订；超标或违规预订时实时提示，把行为拉回合规轨道。

痛点 3 · 行程异常处理慢

航班变动、酒店问题若不及时通知与改签，员工滞留会直接引发企业层面的投诉。

解法 · 行程履约与异常处理

值机、航变、改签全节点即时触达并直连客服，异常处理速度是 TMC 的核心竞争力。

痛点 4 · 报销拖延与续约风险

员工不及时提交报销、财务对账困难；企业管理员看不到节省数据，续约时缺乏依据。

解法 · 报销闭环 + 账户健康预警

行程结束自动催提交与生成发票；向企业管理员定期推送用量与节省报告，支撑续约。

五、核心旅程详细编排

旅程 1：企业开通 + 员工激活

业务痛点

企业开通了账户但员工不知道、不会用，渗透率低，企业续约时看不到价值。

旅程组件配置

进入条件：事件：企业开通后员工账号未激活

提前退出：事件：员工完成首次登录并预订

价值感：面向员工讲"免垫资、自动生成报销单"（而非企业省钱）

渠道：Email 为主（企业邮箱可批量触达）

预期效益

员工激活 +30~50%（估算）；对员工要讲员工的好处，而不是企业的好处。

旅程 2：预订引导 + 合规提示

业务痛点

员工绕开平台线下自订，企业失去管控、TMC 失去交易额与数据。

旅程组件配置

进入条件：事件：差旅申请通过但未在平台预订

分支：属性：预订行为（未预订催办 / 超标预订合规提示）

提前退出：事件：完成平台预订

内容：协议价对比 + 免垫资 + 一键报销的便利性

预期效益

平台渗透率 +25~40%（估算）；渗透率是 TMC 商业价值与企业续约的核心指标。

旅程 3：行程履约与异常处理

业务痛点

航班变动不及时通知导致员工滞留，会直接上升为企业层面的投诉。

旅程组件配置

进入条件：属性：出行前 24h / 事件：航变或行程异常

时间轴：行前提醒 → 值机引导 → 异常即时通知 → 改签协助 → 行程结束

异常优先级：Push + SMS 双通道确保触达，直连 24h 客服

分类：服务类通知，不受任何退订与频控限制

预期效益

投诉下降、满意度提升；异常处理速度是 TMC 区别于普通 OTA 的核心竞争力。

旅程 4：报销与发票闭环

业务痛点

员工拖延提交报销，财务月末对账困难，企业对平台的效率价值感知下降。

旅程组件配置

进入条件：属性：行程结束后未提交报销

递进：行程结束当天 → 3 天后 → 月末截止前（含财务抄送）

内容：已自动生成的报销单与发票，一键提交

提前退出：事件：完成报销提交

预期效益

报销及时率 +35%↑（估算）；财务效率是企业续约时最直接的体感价值。

旅程 5：企业用量与节省报告

业务痛点

企业管理员看不到平台带来的节省与合规改善，续约时缺乏说服自己的依据。

旅程组件配置

进入条件：属性：月度 / 季度报告周期

对象：企业管理员与财务负责人（不发员工）

内容：差旅总额、协议价节省、合规率、渗透率、Top 支出部门

延伸：基于数据提出优化建议与增值服务推荐

预期效益

续约依据与加购机会；量化的节省数据是 B 端续约最有力的武器。

旅程 6：账户健康预警 + 续约保障

业务痛点

企业用量下滑往往到续约时才发现，此时挽回已来不及。

旅程组件配置

进入条件：属性：企业用量环比下滑 / 合同续约前 60 天

分支：属性：企业规模与健康度（大客户转 CSM / 长尾走自动化）

内容：渗透率诊断（哪些部门未使用）+ 改善方案

协同：预警同步给 CSM 与销售，人工与自动化分工

预期效益

企业续约率 +10~20%（估算）；提前 60 天预警给了充分的挽救窗口。

六、渠道选型参考

企业差旅渠道适配相对值（示意）：Email 是 B 端标准通道（行程单、发票、对账、管理员报告均具存证属性），App Push 承载员工行程实时提醒，SMS 用于航变等紧急节点，应用内承载预订引导。

主力通道

Email（行程单、发票、对账单、管理员报告——B 端存证与决策载体）+ App Push（员工行程实时提醒）。

三方角色不可混发

员工收行程与报销、管理员收用量与节省报告、财务收对账——发错对象会造成困扰甚至合规问题。

七、合规与安全（企业级）

企业采购必查项
  • GDPR / SOC 2 Type II 认证
  • 数据驻留与跨境传输合规
  • DPA 数据处理协议支持
差旅数据分级
  • 员工行程与个人信息分级管控
  • 管理员仅可见汇总数据，不越权查看个人隐私
  • PII 脱敏、RBAC 权限、审计留痕
触达护栏
  • 行程与异常类通知不受退订限制（安全需要）
  • 营销与报告类遵循退订与工作时间发送
  • 记录留存可导出，满足企业审计
