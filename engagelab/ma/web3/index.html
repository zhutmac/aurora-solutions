痛点 1 · KYC/身份完成率低

注册后卡在身份验证（交易所 KYC / 钱包创建备份），不完成就无法交易，大量用户在此流失。

解法 · 开户+KYC 催办旅程

注册即触发身份验证引导，Push→Email→WhatsApp→SMS 分层催办，把验证漏损降到最低。

痛点 2 · 入金/首笔交互窗口短

身份完成却不入金、不下第一单/首笔链上交互，早期不激活基本留不住。

解法 · 首次入金首交互黄金期

身份通过即触发，手续费券/新手礼驱动，按"已入金未交易 / 未入金"分层引导。

痛点 3 · 行情来了却没唤醒

大行情波动是最强交易触发点，但缺乏实时事件触达，沉默用户与持仓用户都错过。

解法 · 行情驱动唤醒旅程

价格波动事件即时触发，按持仓/自选分流，把行情转成交易活跃（Web3 独有场景）。

痛点 4 · 安全信任缺失、获客贵

钓鱼、异常登录、提币风险影响留存与口碑；邀请返佣、空投活动靠人工，裂变没做起来。

解法 · 安全信任 + 邀请裂变旅程

OTP 二次确认 / 防钓鱼提示建立信任降流失；邀请返佣、空投任务自动化拉动低成本增长。

五、核心旅程详细编排

旅程 1：开户激活 + 身份/KYC 完成催办

业务痛点

注册后卡在身份验证（交易所 KYC / 钱包创建备份），不完成就无法交易，最大漏损点。

旅程组件配置

进入条件：事件：注册成功

提前退出：事件：身份/KYC 完成

渠道递进：App Push → Email → WhatsApp → SMS（成本由低到高）

转化统计：事件：KYC 完成，监听 3 天

可发送时间：刚注册活跃窗口不加限制；后续触达前加时段

预期效益

KYC 完成 +10~20%（估算）；把验证漏损降到最低，是全链路增长的前提。

旅程 2：首次入金 + 首笔链上交互黄金期

业务痛点

身份完成却不入金、不下第一单/首笔交互，早期不激活基本留不住。

旅程组件配置

进入条件：事件：身份/KYC 通过

提前退出：事件：完成首笔交易/交互

分支：属性：已入金未交易 / 未入金

转化统计：事件：首笔交易，监听 3 天

预期效益

首笔交易 +8~15%（估算）；手续费券/新手礼是首笔转化关键钩子。

旅程 3：行情驱动交易唤醒（Web3 独有）

业务痛点

大行情波动是最强交易触发点，但缺乏实时事件触达，持仓与沉默用户都错过。

旅程组件配置

进入条件：事件：价格波动（如 BTC/自选币 ±5%）

分支：属性：是否持仓/自选该币种

时效：行情类即时下发，不加时段限制

转化统计：事件：打开/交易，监听 6h

预期效益

交易活跃 +15~30%（估算）；持仓/自选用户个性化文案打开率显著高于泛推。

旅程 4：沉睡 / 有资产未活跃召回

业务痛点

沉默用户回归意愿快速衰减；"有余额未动"的用户是最值得召回的高价值群体。

旅程组件配置

进入条件：属性：最后活跃距今 >7 天

分支：属性：沉默深度 7-14 / 15-29 / ≥30 天 + 是否有余额

提前退出：事件：回归活跃

再次进入：可，间隔 15 天

预期效益

召回率 +20~40%（估算）；渠道成本递进 Push→Email→WhatsApp→SMS。

旅程 5：安全信任触达

业务痛点

钓鱼、异常登录、提币风险影响留存与口碑；安全触达不及时会造成资产与信任双重损失。

旅程组件配置

进入条件：事件：异常登录 / 提币 / 新设备 / 授权请求

分支：属性：事件类型（提币登录用 OTP，新设备用 Push）

提前退出：事件：用户确认 / 冻结操作

防钓鱼：触达链接仅指向官方已验证域名

预期效益

可疑操作确认率提升、盗号/钓鱼损失下降；安全体验是 Web3 口碑与留存的基石。

旅程 6：邀请裂变 / 空投任务活动

业务痛点

邀请返佣、空投任务是 Web3 最强低成本增长手段，但靠人工运营、进度提醒缺失。

旅程组件配置

进入条件：事件：空投/邀请活动开启

分支：属性：是否已参与（未参与拉新 / 已参与冲刺）

提前退出：事件：完成任务 / 邀请达标

可发送时间：本地黄金时段 终端时区

预期效益

邀请注册 +15~25%（估算）；返佣到账/名额将满的实时提醒最能催动裂变。

七、合规与安全（Web3 强化）

合规口径
  • KYC / AML 触达，各地监管牌照差异化内容
  • 统一"不构成投资建议 + 高风险提示"免责口径
  • 不推荐具体币种、不做投资诱导
账户与资金安全
  • OTP / 2FA、异常登录提醒、提币二次确认
  • 防钓鱼：官方触达仅指向已验证域名/链接

数据与触达护栏
  • GDPR / CCPA：数据删除/导出/同意管理
  • 频控去重、勿扰时段、终端时区发送
  • 已通过 GDPR、SOC 2 认证，记录留存（如 60 天）
