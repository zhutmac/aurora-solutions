MA · 小刀电动车（两轮电动车）车主运营增长方案

两轮电动车是"一次性高客单硬件 + 长周期售后服务"的生意——车卖出去只是开始， 真正决定 LTV 的是：车主装没装 App、会不会用、保养回不回店、智能服务续不续费、3 年后换不换新车。 小刀智行 App 已具备远程控车、定位防盗、无感解锁、骑行数据与故障报修能力， 本方案以 购车激活绑定、保养周期提醒、智能服务续费、设备离线与车况预警、以旧换新换购、经销商线索与履约 六大旅程切入， 统一编排 极光 App Push + 短信 + 应用内消息 + 经销商 App 四类通道。

极光 App Push（主力） 短信（关键必达） 应用内消息 / 运营位 经销商 App（B 端）

来自小刀智行 App 的现状观察

· 车主服务页显示「智能服务 · 服务中 · 服务有效期」——存在明确的到期与续费节点

· 个人页显示「拥有爱车的第 N 天」——已有精确购车日期，可推算保养、质保与车龄

· 车辆定位页出现「XX 天前更新 · 车辆网络信号弱」——设备长期离线是真实存在的状态

· 常见问题 Top 为「购车后保养周期」「电池耗电快」「APP 无法连接」，首页存在「不会使用 APP 怎么办」提示

注：下文所有转化率、提升幅度为行业估算区间，落地以实测为准。智能服务的赠送期与续费价格以小刀官方政策为准（同类品牌通行为随车赠送一年、到期后按年续费）。

痛点 1 · 买了车不装 App、装了不会用

车主在门店提车后未下载绑定，品牌方完全失去触达能力；即使绑定了，也常停留在"只看电量"，防盗、无感解锁等核心价值未被感知。

解法 · 购车激活与功能跑通旅程

用购车预留手机号发短信引导绑定；绑定后按"是否用过核心功能"分层，逐个引导跑通设防、无感解锁、定位。

痛点 2 · 保养不回店，售后价值流失

车主不清楚保养周期（这正是 App 常见问题第一条），到期不回店，保养与配件收入流向路边店。

解法 · 保养周期精准提醒

按购车日期与骑行里程双维度推算首保与定期保养节点，提前提醒并直连门店预约，把车主留在官方体系内。

痛点 3 · 智能服务静默到期

服务到期后定位、远程控车等功能失效，车主往往在"车找不到了"时才发现，体验受损且续费窗口已过。

解法 · 到期前置续费 + 宽限期挽回

到期前多段提醒并说明"将失去定位与远程控车"，到期后宽限期内继续挽回，把续费做成默认动作。

痛点 4 · 换购需求无人承接

车龄 3 年以上、电池明显衰减的车主正处于换购窗口，若品牌不主动触达，就会在别家门店完成以旧换新。

解法 · 以旧换新引导 + 门店线索闭环

按车龄与电池状态识别换购人群，推旧车估值与国补活动，线索直达经销商 App 并催办跟进。

三、为什么用营销自动化（MA）

车辆档案驱动
  • 购车日期、车型、里程、电池状态、服务到期日作为用户属性
  • 保养、质保、续费、车龄多条周期自动推算并触发
设备事件实时触发
  • 绑定、骑行、离线、电量异常、设防状态秒级触发旅程
  • 设备状态是续费流失与车况服务需求的最强信号
多周期去重护栏
  • 保养、续费、换购、活动可能同期触发，旅程间自动去重
  • 每日/每周频控，避免同一车主被连续打扰
C 端 + B 端协同
  • 车主端做提醒与转化，经销商 App 端做线索催办与履约
  • 线索从触达到到店核销形成闭环，可归因可考核
高可靠触达底座
  • 极光推送聚合华为/小米/OPPO/vivo/荣耀等厂商通道，送达有保障
  • 关键节点 Push 失败自动降级短信，覆盖未装 App 车主
合规与数据安全
  • 车辆定位与轨迹属敏感个人信息，触达内容严格脱敏
  • 营销短信合规退订、频控护栏、发送记录留存可审计

五、核心旅程详细编排

旅程 1：购车激活 —— App 绑定 + 核心功能跑通

业务痛点

门店提车后不下载绑定，品牌完全失去触达能力；绑定后停留在"只看电量"，防盗与无感解锁的价值未被感知。

旅程组件配置

进入条件：事件：购车开票 / 车辆激活但账号未绑定

提前退出：事件：完成绑定且使用过核心功能

分支：属性：绑定状态与已用功能（未绑定 / 已绑未设防 / 已绑未用无感解锁）

渠道：未绑定阶段用购车预留手机号发短信，绑定后转 App Push 与应用内引导

预期效益

绑定率 +25~40%（估算）；绑定与"会用"是后续保养、续费、换购全部运营的前提。

旅程 2：首保与定期保养提醒

业务痛点

「购车后保养周期」是 App 常见问题第一条——车主根本不清楚何时该保养，到期不回店，售后价值流向路边店。

旅程组件配置

进入条件：属性：按购车日期与累计里程推算的保养节点临近

分支：属性：保养类型（首保 / 定期保养 / 质保到期前检测）

提前退出：事件：完成门店预约或到店保养

递进：提前 15 天 App Push → 提前 3 天 Push+短信 → 逾期提醒

预期效益

回店保养 +30~50%（估算）；这是两轮电动车确定性最高、ROI 最好的旅程。

旅程 3：智能服务到期续费

业务痛点

智能服务静默到期后，定位与远程控车失效，车主往往在"车找不到"时才发现，体验受损且续费窗口已过。

旅程组件配置

进入条件：属性：智能服务到期前 30 天

分支：属性：功能使用深度（常用定位防盗 / 低频使用）

递进：T-30 应用内 → T-7 Push → T-1 Push+短信 → 到期后宽限期挽回

说明：赠送期与续费价格以官方政策为准，文案中如实告知权益与到期影响

预期效益

续费率 +20~35%（估算）；对高频使用定位防盗的车主，"功能将失效"比价格优惠更有说服力。

旅程 4：设备离线与车况预警

业务痛点

车辆长期不上报（App 显示"信号弱、N 天前更新"）意味着智能功能形同虚设，既影响体验也是续费流失前兆；「电池耗电快」也是高频问题。

旅程组件配置

进入条件：事件/属性：车辆连续 N 天未上报数据 / 电池状态异常

分支：属性：异常类型（设备离线排障 / 电池衰减到店检测）

提前退出：事件：设备恢复上报 / 完成到店检测

合规：触达仅提示"车辆状态异常"，不在消息中展示具体位置信息

预期效益

离线恢复与到店检测提升；离线排障同时保住了智能服务续费与车主体验。

旅程 5：以旧换新与换购引导

业务痛点

车龄 3 年以上、电池明显衰减的车主正处于换购窗口，品牌不主动触达就会在别家门店完成以旧换新，老客白白流失。

旅程组件配置

进入条件：属性：车龄达阈值（如 3 年+）/ 电池衰减明显 / 国补活动期

分支：属性：换购意向信号（浏览过新车 / 仅车龄到期）

内容：旧车估值 + 国补与品牌补贴 + 门店预约（承接门店引流）

闭环：产生的换购线索实时同步经销商 App，进入 J6 跟进

预期效益

换购线索 +25~40%（估算）；老客换购的成交率与获客成本都显著优于纯新客。

旅程 6：经销商线索跟进与履约催办（B 端）

业务痛点

线索派给门店后不及时跟进就快速冷却；保养预约与维修工单履约不透明，总部无法掌控终端服务质量。

旅程组件配置

进入条件：事件：线索分配门店 / 车主预约到店 / 工单超时未处理

递进：30min 未响应提醒 → 4h 未响应升级 → 24h 未响应建议重新分配

分支：属性：任务类型（换购线索 / 保养预约 / 维修工单）

渠道：经销商 App 推送为主，超时升级用短信触达店主

预期效益

线索响应时效 +40%↑（估算）；终端响应速度直接决定 C 端触达带来的线索能否转成成交。

六、国内渠道选型参考

国内两轮电动车场景的渠道适配相对值（示意）：极光 App Push 是车主端主力（成本近零、可承载全部周期提醒），短信用于未装 App 车主与到期类必达节点，应用内消息承接续费与换购转化，经销商 App 覆盖 B 端。

主力通道

极光 App Push（保养、续费、车况、活动全部周期提醒，聚合主流厂商通道保障送达）+ 应用内消息（续费与换购转化路径最短）。

短信是覆盖缺口的关键

大量车主提车后未装 App——购车激活阶段与智能服务到期等关键节点必须用购车预留手机号发短信兜底，否则这批人完全触达不到。

七、合规与安全

车辆定位与轨迹
  • 定位与骑行轨迹属敏感个人信息，触达内容不展示具体位置
  • 仅提示"车辆状态异常，请打开 App 查看"
  • 遵循个人信息保护法与最小必要原则
营销触达合规
  • 营销短信需具备退订方式并遵守发送时段规范
  • 服务类通知（保养、到期、车况）与营销类分类管理
  • 如实告知服务权益与到期影响，不做误导性表述
数据与触达护栏
  • 多周期旅程去重与合并，避免同一车主被连续打扰
  • 每日/每周频控、勿扰时段（避免夜间打扰）
  • PII 脱敏、权限管控、发送记录留存可审计
