痛点 1 · KYC 完成率低

注册后卡在身份认证与资料提交，每流失 1 个百分点就对应大量潜在借款人，直接压缩可放款盘子。

解法 · KYC 中断挽回旅程

按中断环节分层催办（未上传证件 / 未活体 / 待补资料），Push→WhatsApp→SMS 递进，把断点接回。

痛点 2 · 授信通过却不借款

授信额度发下去无人使用，7 日黄金期一过转化率大幅下滑，风控与获客成本被白白消耗。

解法 · 首借 7 日黄金期旅程

授信通过即触发，用"额度有效期 + 首借免息/费率优惠"驱动，分层递进把窗口用满。

痛点 3 · 贷后催收依赖人工

还款提醒与逾期跟进靠人工外呼，成本高、覆盖不全，M0 自愈率上不去。

解法 · 还款提醒 + 逾期分级

还款日前多段自动提醒；逾期按 D+1/D+7/D+15 分级，合规话术递进，显著降低人工催收成本。

痛点 4 · 结清后沉默不复借

用户还完就走，缺乏复借唤起与额度提升引导，LTV 无法释放。

解法 · 复借召回 + 额度提升唤起

按沉默天数与历史履约质量分层召回；对优质无逾期用户主动推额度提升，安全放大 LTV。

五、核心旅程详细编排

旅程 1：KYC 中断挽回

业务痛点

注册后卡在身份认证与资料提交，直接压缩可放款人群规模。

旅程组件配置

进入条件：事件：注册成功且 KYC 未完成

分支：属性：中断环节（未上传证件 / 未活体 / 待补资料）

提前退出：事件：KYC 通过

可发送时间：每天 9:00-21:00 终端时区（合规勿扰）

预期效益

KYC 完成 +10~15%（估算）；按中断环节给出精准指引比泛泛催办有效得多。

旅程 2：首借激活 7 日黄金期

业务痛点

授信额度发下去无人使用，7 日黄金期一过转化断崖下滑。

旅程组件配置

进入条件：事件：授信通过且无借款记录

提前退出：事件：完成首笔借款

递进：D+1 Push → D+3 WhatsApp → D+6 SMS（额度将到期）

转化统计：事件：首借成功，监听 7 天

预期效益

首借转化 +8~12%（估算）；"额度有效期 + 首借优惠"是最有效的组合钩子。

旅程 3：还款提醒（贷后管理）

业务痛点

还款提醒靠人工外呼，成本高、覆盖不全，非恶意逾期占比高。

旅程组件配置

进入条件：属性：还款日前 3 天

递进：T-3 Push → T-1 Push+SMS → 当日 WhatsApp

提前退出：事件：完成还款

合规：纯提醒性话术，勿扰时段强约束

预期效益

催收人力成本 -30~50%（估算）；提前提醒可显著减少非恶意逾期。

旅程 4：逾期分级提醒

业务痛点

逾期跟进缺乏分级策略，人工覆盖不到长尾，M0 自愈率低。

旅程组件配置

进入条件：属性：还款日后 D+1 未还款

分支：属性：逾期天数与金额（D+1 / D+7 / D+15）

提前退出：事件：完成还款

合规：话术符合当地催收规范，禁止骚扰性表述与第三方联系人触达

预期效益

M0 自愈率 +10~20%（估算）；自动化承接长尾，人工聚焦高风险案件。

旅程 5：沉默用户复借召回

业务痛点

结清后用户沉默不复借，是最大的沉没资产，LTV 无法释放。

旅程组件配置

进入条件：属性：结清后 30 天未复借

分支：属性：沉默深度 + 历史履约质量（优质无逾期 / 一般）

提前退出：事件：发起新借款

再次进入：可，间隔 30 天

预期效益

复借率 +20~40%（估算）；对优质履约用户给予更优费率是最有效的召回。

旅程 6：额度提升唤起

业务痛点

优质用户额度长期不变，借款金额与频次受限，LTV 释放不足。

旅程组件配置

进入条件：属性：历史借款 ≥2 笔且无逾期记录

前置：需风控系统预先核定可提额名单，MA 仅负责触达

提前退出：事件：完成提额申请 / 新借款

可发送时间：每天 9:00-21:00 终端时区

预期效益

复借金额 +6~10%（估算）；在风控许可范围内安全放大优质用户 LTV。

七、合规与安全（金融强化）

金融监管合规
  • KYC / AML 流程触达，各地牌照与监管差异化
  • 催收话术符合当地规范：禁止骚扰性表述
  • 不向第三方联系人（通讯录）触达
勿扰与频控
  • 严格勿扰时段（终端时区 9:00-21:00）
  • 每日/每周触达上限，旅程内自动去重
  • 用户还款后立即停止全部催收类触达
数据与留痕
  • 全链路 TLS、PII 脱敏、手机号哈希、RBAC
  • 触达记录留存可导出，满足合规审查与审计
  • 已通过 GDPR、SOC 2 认证
