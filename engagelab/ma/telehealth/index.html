EngageLab MA · 在线医疗问诊平台增长方案

医疗平台的增长本质是"就医闭环的完成度"——注册后不建档就无法问诊、问诊后不取药不复诊就没有疗效、 慢病患者断药断访直接影响健康结果。医疗场景的触达首先是服务与安全，其次才是增长。 本方案以 建档激活、问诊履约提醒、处方取药与用药提醒、复诊与随访、慢病周期管理、医生端接诊效率 六大旅程切入， 统一编排 App Push + SMS + Email 三类通道（触达内容严格脱敏）。

注：下文所有转化率、提升幅度为在线医疗行业估算区间，落地以实测为准。本方案面向持牌合规医疗平台，所有触达不构成诊疗建议、不含病情与诊断信息。

痛点 1 · 注册后不建档

健康档案不完整就无法精准匹配医生与开具处方，用户第一次求医就受阻而流失。

解法 · 建档激活旅程

按缺失项精准引导（基础信息 / 过敏史 / 既往史），强调"完善后可快速匹配对应科室医生"。

痛点 2 · 问诊爽约与履约断层

预约了不上线、医生等不到患者，双方时间浪费，平台口碑与医生留存双受损。

解法 · 问诊履约强时效提醒

预约确认、问诊前 24h/15min 多通道提醒（SMS 兜底），显著降低爽约率。

痛点 3 · 开方后不取药、疗程中断

处方开了不购药、买了药不按时服用，疗效无法保证，平台价值也无法体现。

解法 · 取药与用药周期提醒

处方未购药提醒；按疗程周期做服药提醒与余量补药提醒，把疗效闭环做实。

痛点 4 · 复诊与慢病随访缺位

慢病患者需要长期随访与复诊，缺乏自动化跟进就会断访，健康结果与 LTV 双失。

解法 · 复诊随访 + 慢病周期管理

按病程建议周期自动提醒复诊与指标监测（血压/血糖），形成长期健康管理关系。

五、核心旅程详细编排

旅程 1：健康档案建档激活

业务痛点

档案不完整就无法精准匹配医生与开方，用户第一次求医受阻即流失。

旅程组件配置

进入条件：事件：注册成功且档案不完整

分支：属性：缺失项（基础信息 / 过敏史 / 既往史）

提前退出：事件：档案完整度达标

合规：文案仅提示"完善档案"，不涉及任何具体健康信息

预期效益

建档完成 +25~40%（估算）；档案是问诊、开方与随访的前提。

旅程 2：问诊履约提醒（防爽约）

业务痛点

预约了不上线、医生等不到患者，双方时间浪费，平台口碑与医生留存双受损。

旅程组件配置

进入条件：事件：预约问诊成功

时间轴：预约确认 → T-24h 提醒 → T-15min 提醒（Push+SMS）→ 未上线补触达

分类：服务类通知，不受营销退订与频控限制

双端：患者与医生同步提醒，减少双方爽约

预期效益

爽约率下降 30~50%（估算）；SMS 兜底确保关键节点不遗漏。

旅程 3：处方取药 + 用药提醒

业务痛点

处方开了不购药、买了药不按时服用，疗效无法保证，平台价值无法体现。

旅程组件配置

进入条件：事件：处方开具

阶段：未购药提醒 → 按疗程周期服药提醒 → 余量不足补药提醒

合规：文案不出现药品名与病情，仅提示"有待处理的处方/用药提醒"

提前退出：事件：完成购药 / 疗程结束

预期效益

取药率 +20~35%（估算）；用药依从性提升同时带来复购与疗效双重价值。

旅程 4：复诊与疗效随访

业务痛点

疗程结束后无跟进，患者不知是否需要复诊，平台失去持续服务关系。

旅程组件配置

进入条件：属性：疗程结束 / 医生建议复诊日临近

分支：属性：是否已购药（已购药随访疗效 / 未购药先提醒取药）

提前退出：事件：完成复诊预约

内容：疗效自评问卷 + 复诊预约入口（不含诊断建议）

预期效益

复诊率 +25~40%（估算）；随访是医疗平台建立长期关系的核心动作。

旅程 5：慢病周期管理

业务痛点

慢病患者需长期用药与指标监测，断药断访直接影响健康结果与平台 LTV。

旅程组件配置

进入条件：属性：慢病管理用户

周期：按建议频率循环——指标记录提醒 → 用药续方提醒 → 定期复诊

分支：属性：依从性（良好维持 / 依从性下降加强跟进）

再次进入：周期性持续运行，直至用户退出管理计划

预期效益

旅程 6：医生端接诊效率提醒

业务痛点

医生不及时接诊导致患者等待流失；医生在线时长不足则供给不够。

六、渠道选型参考

在线医疗渠道适配相对值（示意）：App Push 承载服务提醒主力，SMS 是问诊与用药关键节点的必需兜底（触达率最高），Email 承载报告与账单；医疗场景不使用 WhatsApp 等第三方社交通道传递健康相关信息。

主力通道

App Push（问诊、用药、随访服务提醒）+ SMS（问诊即将开始、处方待取等关键节点必须触达）。

内容脱敏是红线

所有通道的触达文案均不得出现病情、诊断、药品名等敏感信息，仅提示"有待处理事项，请打开 App 查看"。
